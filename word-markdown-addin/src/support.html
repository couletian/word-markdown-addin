Markdown 工具箱

在 Microsoft Word 与 Markdown 之间双向转换，全部处理都在本机完成，文档不会离开你的电脑。

三个核心功能

功能位置说明
导出 Markdown 功能区「导出 Markdown」 把当前文档转成 .md，保留标题、列表、加粗、斜体、表格、链接、代码块。
粘贴 Markdown 功能区「粘贴 Markdown」 先在别处复制 Markdown 文本，点击后自动转成 Word 富文本插入光标处。
导入 .md 文件 侧边面板「导入」选项卡 选择本地 .md 文件，生成排版完整的 Word 文档内容。

加载项没出现在功能区？

  1. 确认启动器窗口还开着，服务处于运行状态。
  2. 完全关闭 Word（检查任务管理器里没有 WINWORD.EXE），再重新打开。
  3. 仍没有的话：点击「插入」→「我的加载项」→ 顶部「共享文件夹」→ 选择「Markdown 工具箱」→「添加」。
  4. 还是没有：在「插入」→「我的加载项」→「上传我的加载项」里，选择 %LOCALAPPDATA%\MarkdownToolbox\catalog\manifest.xml 手动加载。
提示：加载项指向的是 https://localhost:3000，所以启动器必须保持运行。 关掉启动器窗口，功能区按钮就会失效。

常见问题

端口被占用怎么办？
用命令行启动并换端口：Markdown工具箱.exe --port 3001， 然后编辑 manifest.xml 里的 3000 为 3001，重新运行一次即可。

HTTPS 证书警告？
首次运行会把自签名证书加入「当前用户 → 受信任的根证书颁发机构」。若浏览器仍提示， 关闭浏览器重开一次即可。

想彻底卸载？
运行 Markdown工具箱.exe --uninstall，会清理注册表项与本地目录。

支持的 Markdown 语法

  • 标题 # ~ ######，以及 Setext 式下划线标题
  • 无序列表 - * +、有序列表 1.，支持嵌套
  • 加粗 **text**、斜体 *text*、删除线 ~~text~~、行内代码
  • 表格（含对齐语法）、引用块、围栏代码块
  • 链接 [text](url)、自动链接 <url>、图片
  • 水平分隔线、硬换行（行尾两个空格或反斜杠）
